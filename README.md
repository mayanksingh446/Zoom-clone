# Zoom Clone – Real-Time Video Conferencing App

A full-stack video conferencing application inspired by Zoom that allows users to connect with others through real-time video and audio communication. The application supports online meetings, screen sharing, and real-time communication.

## 🚀 Live Demo

**[Click here to visit the Live Application](https://zoom-clone-frontend-g30n.onrender.com/)**

## ✨ Features

- **Real-Time Video Calling:** Connect with other users through video calls.
- **Audio Communication:** Communicate with participants using audio.
- **Screen Sharing:** Share your screen with other participants during meetings.
- **Real-Time Communication:** Uses Socket.IO for real-time communication between users.
- **WebRTC Integration:** Enables peer-to-peer audio and video communication.
- **Responsive UI:** User-friendly interface for a smooth experience.
- **Meeting Functionality:** Join and participate in online meetings.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd Zoom-Clone
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 4. Install Backend Dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 5. Configure Environment Variables

Create a `.env` file in the required directories and configure the environment variables used by your application.

### 6. Run the Application

Start the backend server:

```bash
npm start
```

Start the frontend application:

```bash
npm run dev
```
